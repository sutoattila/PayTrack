# PayTrack

A simple Flask web application.

## Setup Instructions

### 1. Clone the repository
```bash
git clone <repository_url>
cd PayTrack
```
### 2. Install dependencies
```bash
python3 -m venv venv
source venv/bin/activate
pip install flask
```
### 2. Start server
```bash
python app.py
```
#### The app is at http://127.0.0.1:5000
